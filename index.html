Formulas & assumptions

Ph = ρ · g · Q · H / 3.6×10⁶ [kW], g = 9.81 m/s²

ηduty = ηBEP · r(2 − r), r = Q / QBEP — parabolic part-load approximation

Pshaft = Ph / ηduty · Pin = Ph / (ηduty · ηmotor)

Eyr = Pin · hours · tariff · TCO = CapEx + n·Eyr + n·Maint (undiscounted, constant tariff)

CO₂ = Pin · hours · EF / 1000 [t/yr]

Driver check (API 610): nameplate ≥ Pshaft × 1.25 (<22 kW) / 1.15 (22–55 kW) / 1.10 (>55 kW)

Rated flow 80–110% of BEP (minor), outside 70–120% (major) · NPSH margin ≥ 1.0 m · Material class ranking simplified from API 610 Annex H

Recommendation = lowest TCO among bids with no major deviation. Commercial flags do not affect compliance.

Physics in the browser.
Language models only where language is the problem.

A language model reads quotations. It never computes a head, a power or a cost. Every engineering number comes from closed-form equations you can inspect in the page source.

Deterministic Physics Layer

Darcy–Weisbach friction with Swamee–Jain, affinity laws, NPSHa, API 610 driver margins and lifecycle cost — executed in your browser. Same inputs, same outputs, every time.

  • engine.js · pure functions
  • No model in the calculation path
  • Formulas printed in every audit report

L2

Dual-Cloud Document Extraction

Optional. Quotation text goes to Microsoft Azure AI Foundry (or an Azure OpenAI deployment) or to Google Gemini, with a fixed schema and the instruction to return null rather than guess. Results are cross-checked against the local parser before you insert them.

  • Azure: api-key · your endpoint
  • Gemini: x-goog-api-key · your model
  • Local regex fallback · no key
L3

Zero-Retention EPC Privacy

Bring your own key. There is no MYENG backend in the Sandbox: the site is static, keys stay in tab memory, and workspaces are not saved anywhere. Vendor pricing only leaves the browser if you choose a cloud parser — and then only to your own account.

  • Static hosting · no cookies · no analytics
  • No localStorage for keys or bids
  • Reload = clean slate
What we do not claim

The Studio does not replace vendor-certified performance curves, witnessed tests or your company's specification. It makes the comparison faster to build and easier to check.
